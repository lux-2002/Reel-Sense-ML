# Notebook plan

The three notebooks are intentionally part of the repository's main evidence layer.

1. **01_exploration.ipynb** — complete dataset audit, schema, missingness, duplicates, target distribution, numerical/categorical distributions and initial relationships.
2. **02_model_development.ipynb** — leakage-safe train/test split, preprocessing pipelines, baseline models, categorical encoding, TF-IDF integration and model comparison.
3. **03_model_evaluation.ipynb** — cross-validation, final metrics, residual analysis, worst errors, feature-group experiments and conclusions.
